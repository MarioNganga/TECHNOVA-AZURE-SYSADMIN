# 01 — Création du groupe de ressources Azure

## Objectif

Créer un groupe de ressources Azure pour centraliser et organiser les ressources du laboratoire TECHNOVA.

## Configuration

| Paramètre | Valeur |
|---|---|
| Nom | RG-TECHNOVA-LAB |
| Abonnement | Azure for Students |
| Région | France Central |

## Réalisation

Le groupe de ressources `RG-TECHNOVA-LAB` a été créé depuis le portail Azure.

Il servira à regrouper les ressources de l'infrastructure TECHNOVA.
